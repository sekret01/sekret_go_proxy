# SEKRET GO PROXY

> **start:** 26.08.2026  
> **version:** MVP

Двухуровневый прокси с шифрованием и модульной архитектурой.

## Быстрый старт

### Сборка

```bash
# Linux
chmod +x build/biuld.sh
./build/biuld.sh

# Windows
build\build.bat
```

### Запуск клиента

```bash
# Linux
./build/_result_lin/client

# Windows
build\_result_win\client
```

### Запуск сервера

```bash
# Linux
./build/_result_lin/server

# Windows
build\_result_win\server
```

### Настройка

Файлы конфигураций `client.yaml` и `server.yaml` лежат в дерикториях:

```bash
# Linux
build/_result_lin/configs

# Windows
build/_result_lin/configs
```
