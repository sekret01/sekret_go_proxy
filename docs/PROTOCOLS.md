# Протоколы программы

## Simple (SimpleFramer)

### Формат сообщения

|Поле|Размер|Описание|
|-|-|-|
|метка|1 байт|магическое число для идентификации|
|тип|1 байт|тип передаваемого сообщения|
|ID|16 байт|UUID запроса|
|длина|4 байта|длина данных|
|данные|N байт|исходные данные|

### Типы сообщений

| Тип | Значение | Данные |
|-----|----------|--------|
| `MsgConnect` | 0x01 | HTTP-запрос/ответ или TLS-байты |
| `MsgData` | 0x02 | Хост:порт (например, `example.com:80`) |
| `MsgClose` | 0x03 | (пусто) |
| `MsgError` | 0x04 | Текст ошибки |
