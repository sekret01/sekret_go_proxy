# Лист конфигурации

## Клиент

### connection

|конфиг|описание|доступные значения|
|-|-|-|
|**connection_type**|тип подключения|proxy, vpn|
|**localhost**|хост:порт, на котором будут прослушиваться запросы для отправления на сервер|пример: 127.0.0.1:33333, :33333|
|**remotehost**|хост:порт сервера / промежуточного узла, куда будет настраиваться туннель|пример: 123.123.123.123:33333, example.some-domen:33333|
|**pprofhost**|хост:порт выхода в pprof для дебага|пример: 0.0.0.0:6060, :6060|
|**connection_limit**|[только клиент] лимит на одновременное количество подключений|1024, 1000000, смотрите по железу|

### modules

Описаны в [архитектуре](/docs/ARCHITECTURE.md).

### logs

|конфиг|описание|доступные значения|
|-|-|-|
|**log_level**|уровень логирования|DEBUG, INFO, WARNING, ERROR, CRITICAL|

### filter [только клиент]

|конфиг|описание|доступные значения|
|-|-|-|
|**active**|включен / выключен|true, false|
|**filter_type**|тип фильтра|default|
|**addresses**|список адресов, которые будут проходить в фильтр|пример: [yandex.net, ...], []|
|**domain**|домен, все адреса которого будут фильтроваться|примеры: ru, com|
|**server.host**|хост:порт сервера-фильтра|пример: 127.0.0.1:44444|
|**server.transport**|тип транспорта|подробнее: [архитектура](/docs/ARCHITECTURE.md#доступные-модули-для-выбора-в-конфиге), рекомендуется: tcp|
|**server.framer**|тип фреймера|подробнее: [архитектура](/docs/ARCHITECTURE.md#доступные-модули-для-выбора-в-конфиге), рекомендуется: default|
|**server.encryptor**|тип шифровальщика|подробнее: [архитектура](/docs/ARCHITECTURE.md#доступные-модули-для-выбора-в-конфиге), рекомендуется: default|
|**server.dispatcher**|тип диспетчера|подробнее: [архитектура](/docs/ARCHITECTURE.md#доступные-модули-для-выбора-в-конфиге), рекомендуется: default|
|**server.auth**|тип авторизации|подробнее: [архитектура](/docs/ARCHITECTURE.md#доступные-модули-для-выбора-в-конфиге), рекомендуется: default|

Для всех модулей сервера-фильтра рекомендуется ставить `default`, так как они являются самыми простыми и быстрыми в системе.

### dns [только клиент]

|конфиг|описание|доступные значения|
|-|-|-|
|**active**|включен / выключен|true, false|
|**host**|хост:порт dns|пример: 0.0.0.0:5353, :5353|
|**upstream**|хост:порт для вышестоящего DNS|любой существующий DNS, пример: 8.8.8.8:53|

### admin

|конфиг|описание|доступные значения|
|-|-|-|
|**adminhost**|хост:порт, на котором будет крутиться вуб-админка. Нужна для более удобного управления|пример: 127.0.0.1:12345|
|**authentication**|требуется ли авторизация для входа в вуб-админку|none (нет), default (логин-пароль)|
|**user**|login для входа в админку|текст|
|**password**|пароль для входа в админку|текст|
|**auto_run_proxy**|параметр, отвечающий за запуск прокси сразу после запуска приложения|true (автозапуск), false (запуск только через вкб-админку)|
