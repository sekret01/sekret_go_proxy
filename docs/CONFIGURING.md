# Лист конфигурации

## Клиент

### connection

|конфиг|описание|доступные значения|
|-|-|-|
|**connection_type**|тип подключения|proxy, vpn|
|**localhost**|хост:порт, на котором будут прослушиваться запросы для отправления на сервер|пример: 127.0.0.1:33333|
|**remotehost**|хост:порт сервера / промежуточного узла, куда будет настраиваться туннель|пример: 123.123.123.123:33333, example.some-domen:33333|

### modules

Описаны в [архитектуре](/docs/ARCHITECTURE.md).

### logs

|конфиг|описание|доступные значения|
|-|-|-|
|**log_level**|уровень логирования|DEBUG, INFO, WARNING, ERROR, CRITICAL|

### secure

|конфиг|описание|доступные значения|
|-|-|-|
|**key_32_bytes**|ключ 32 байта для шифровальщика|любой набор из 32 цифр, но ключ должен совпадать с ключем на сервере|

### admin

|конфиг|описание|доступные значения|
|-|-|-|
|**adminhost**|хост:порт, на котором будет крутиться вуб-админка. Нужна для более удобного управления|пример: 127.0.0.1:12345|
|**authentication**|требуется ли авторизация для входа в вуб-админку|none (нет), default (логин-пароль)|
|**user**|login для входа в админку|текст|
|**password**|пароль для входа в админку|текст|
|**auto_run_proxy**|параметр, отвечающий за запуск прокси сразу после запуска приложения|true (автозапуск), false (запуск только через вкб-админку)|
