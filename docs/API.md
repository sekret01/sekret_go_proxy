# API программы (для веб-админки)

## Web GUI

### Аутентификация

Роут: `/login`  
Метод: `GET`  
Приватный: `нет`  
Возврат: страница аутентификации  

### Главная страница

Роут: `/home`, `/`  
Метод: `GET`  
Приватный: `да`  
Возврат: главная страница  

### Список пользователей

Роут: `/users`  
Метод: `GET`  
Приватный: `да`  
Возврат: страница пользователей  

### Логи

Роут: `/logs`  
Метод: `GET`  
Приватный: `да`  
Возврат: страница логов
